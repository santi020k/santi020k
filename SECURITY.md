# Security policy

This repository renders Santiago Molina's public GitHub profile and contains
small automation scripts. It does not ship a library, application, or service.

If you find a security issue in the automation, please use GitHub's private
vulnerability reporting for this repository when available. Otherwise, email
[hi@santi020k.com](mailto:hi@santi020k.com). Please do not open a public issue
for a vulnerability.

Include the affected workflow or script, reproduction steps, and potential
impact. Reports will be acknowledged as soon as practical.
